# こもれびタイル

同じ絵柄を3枚選んで消す、スマートフォン向けのタイルゲームです。

## 遊び方

- 一番上のタイルをタップして7枠の置き場に移します。
- 同じ絵柄が3枚そろうと消えます。すべて消すと次のステージへ進みます。
- ステージごとに枚数が増え、2ステージごとに絵柄の種類が増えます。最大90枚・12種類です。
- 時間制限なし。戻す・ヒント・置き場が満杯のときのお助けが使えます。
- 進行状況は使用中のブラウザに自動保存されます。別の端末やURLとは同期しません。
- 音は右上の音符ボタンでオンにできます。

## GitHub Pagesの初回設定

Settings → Pages → Build and deployment で次のように設定します。

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

公開先（設定・デプロイ完了後）: https://shimizutom1981-ship-it.github.io/komorebi-tiles/

## 開発と管理

`index.html` だけで動作する静的アプリです。ビルドや外部ライブラリは不要です。このGitHubリポジトリをソースコードの正本とします。以前のSites試作版とは自動同期しません。
